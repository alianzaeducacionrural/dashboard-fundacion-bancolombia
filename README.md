# Dashboard Aliados Fundación Bancolombia

Sitio estático (sin build). Para actualizar datos: reemplaza `../Base de datos.xlsx`, ejecuta `python build_data.py` y sube los cambios.
Publicar: subir esta carpeta a un repo y activar GitHub Pages (Settings → Pages → rama main, carpeta raíz o /docs).
Los nombres de personas se excluyen al generar los datos.
